
# MonEcole

MonEcole is an in-progress school management application built with Spring Boot and PostgreSQL.

This version is the structured evolution of my earlier school management project. It is being built progressively with a cleaner backend architecture, DTO-based data flow, JWT authentication, role-based access control, and modules designed to remain maintainable as the project grows.

## Current Status

This project is **still in progress**.

At this stage, the focus is on building a clean and scalable backend foundation rather than a fully finished product.

## Purpose

The goal of this project is to build a school management system that can handle core academic and administrative operations such as:

- user authentication and authorization
- employee and user management
- school-related modules such as filières, matières, and other academic entities
- timetable generation
- maintainable backend architecture ready for future frontend integration

## What Has Been Built So Far

So far, the project includes or is being built around:

- Spring Boot backend structure
- layered architecture with separated controller / service / repository / DTO logic
- PostgreSQL integration
- JWT-based authentication
- role-based access control
- DTO-based request / response handling
- global exception handling and validation structure
- modular organization intended to support future expansion
- preparation for integration with a more modern frontend later

## Technical Stack

- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Security:** Spring Security, JWT
- **Architecture style:** layered architecture with DTOs
- **Templating / current UI direction:** Thymeleaf in current phase, with possible React integration later
- **Build tool:** Maven

## Project Objective

This project is not just a demo. It is also part of a practical long-term effort to build a cleaner, more professional full-stack application with real structure, better maintainability, and stronger backend foundations.

## Work in Progress Notes
